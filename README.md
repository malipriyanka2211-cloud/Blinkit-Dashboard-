# Project Overview

This project is an interactive Blinkit Sales Dashboard built using Power BI. It analyzes sales performance, outlet trends, item distribution, and customer behavior to generate meaningful business insights
# Objective

To evaluate Blinkit’s business performance using key KPIs and visual analytics for better decision-making.

# Key Insights
Total Sales: 1.20M
Average Rating: 3.93
Top performing outlet type: Supermarket Type1
Medium and Small outlets contribute the highest sales
Tier 3 locations show strong sales performance
Household items and snacks are top-selling categories

# Tools Used
Power BI
Data Visualization
Data Cleaning & Transformation

# Dashboard Features
Sales by Outlet Location, Type, and Size
Item Type Performance Analysis
Rating distribution by product category
Interactive filters (Outlet size, year, fat content)

# Conclusion

This dashboard helps understand Blinkit’s sales patterns and supports data-driven business decisions through clear and interactive visualizations.
